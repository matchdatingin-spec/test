# Day 65 — Time Connectors — when, while, before, after, until, as soon as

നമസ്കാരം. ഇന്ന് രണ്ട് events തമ്മിലുള്ള time relationship clear ആക്കുകയാണ്. Malayalam-ൽ പലപ്പോഴും context മതി. English listener-ന് ഏത് event ആദ്യം, ഏത് event ഒരേ സമയത്ത്, ഏത് point വരെ, ഏത് event വന്ന ഉടനെ എന്നത് connector വഴി കാണിച്ചാൽ explanation വളരെ എളുപ്പം follow ചെയ്യാം.

ഇന്നത്തെ six time connectors are when, while, before, after, until, and as soon as. ഇവ sequence words ആയി memorize ചെയ്യുന്നതിന് മുമ്പ് ഓരോന്നും മനസ്സിൽ ഒരു time picture ഉണ്ടാക്കണം.

ആദ്യം when. When എന്നത് ഒരു event സംഭവിക്കുന്ന time-നോട് മറ്റൊരു event connect ചെയ്യുന്നു. Sometimes repeated routine, sometimes one particular moment. Core meaning: at that time.

Door opening process നടക്കുന്നതിനിടയിലാണ് ringing. While overlap കൂടുതൽ clearly കാണിക്കുന്നു.

ഇനി before. Before means earlier than another event. Timeline-ൽ first event connector ഇല്ലാത്ത main action ആകാം, second reference event before part-ൽ വരാം.

Sentence begins with leaving words, പക്ഷേ before tells us locking happened earlier than leaving.
